# O Senhor dos Anéis | Landing Page

Uma landing page desenvolvida em Next.js inspirada na obra **O Senhor dos Anéis**, de **J. R. R. Tolkien**.

O objetivo do projeto é apresentar um layout moderno utilizando Grid Layout, componentes responsivos e integração com Inteligência Artificial para geração de conteúdo.
