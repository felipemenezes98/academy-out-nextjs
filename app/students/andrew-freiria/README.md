# Earth Watch — Andrew Freiria

Estrutura criada para ser colocada na pasta `andrewfreiria` do projeto compartilhado.

## Observações

- Os imports `@/components/ui/...` pressupõem que os componentes shadcn/ui já existentes no projeto compartilhado permaneçam acessíveis.
- Os arquivos usam `@/andrewfreiria/...` como alias para manter a implementação isolada dentro da pasta.
- Caso o alias `@` não esteja configurado para a raiz do projeto, ajuste apenas os imports conforme a configuração existente.
- O tema claro/escuro utiliza a classe `dark` no elemento `html`.
- Os dados em `data/objects.ts` são inteiramente fictícios.
