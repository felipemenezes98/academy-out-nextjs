# DevPilot AI

> **Your AI Software Engineer.**

Uma landing page moderna desenvolvida em **Next.js**, **TypeScript**, **Tailwind CSS** e **shadcn/ui**, criada como parte do projeto **CCM Academy Out**.

O objetivo desta landing é apresentar o conceito do **DevPilot AI**, uma inteligência artificial que acompanha desenvolvedores durante todo o ciclo de desenvolvimento de software, oferecendo sugestões inteligentes, revisão de código e auxílio técnico em diversas etapas do projeto.

---

## Sobre o projeto

O **DevPilot AI** é um conceito fictício inspirado em ferramentas modernas de desenvolvimento como GitHub Copilot, Cursor e Claude Code.

A proposta é demonstrar como uma IA poderia atuar como um verdadeiro engenheiro de software, auxiliando desde a escrita de código até revisões, documentação e arquitetura de aplicações.

Entre as funcionalidades apresentadas estão:

- Pull Request Review
- Code Explanation
- Documentation Generation
- Bug Detection
- Architecture Suggestions
- Test Generation
- AI Workspace

Toda a landing foi construída utilizando conteúdo estático, sem consumo de APIs, priorizando uma arquitetura organizada, componentizada e preparada para futuras evoluções.
