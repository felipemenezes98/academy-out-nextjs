# Computer OS

## Sobre o projeto

Este projeto é uma aplicação de conceitos aprendidos durante a aula de Front-end com IA, ministrada por Felipe Menezes da CCM, o projeto une minha maior paixão, os computadores, com elementos visuais interessantes.

---

## Objetivo

Apresentar conceitos de computadores através de uma interface visual e interativa.

---

## Desenvolvimento

Projeto desenvolvido utilizando conceitos de:

- Front-end
- Componentização
- Interfaces visuais
- Experiência do usuário

---

## Tema

O projeto possui como tema principal:

- Computadores
- Hardware
- Software
- Elementos visuais relacionados à tecnologia

---

## Tecnologias utilizadas

- React
- Next.js
- TailwindCSS
